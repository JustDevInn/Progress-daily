# DailyProgress

DailyProgress is a mobile-first gym progress tracker built with Vite, React, Firebase Auth, and Firestore. It also supports local-only use for training without an account.

## Local Setup

Install dependencies:

```bash
npm install
```

Start the local dev server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

## Environment Variables

Copy `.env.example` to `.env` and fill in the Firebase web app values:

```bash
cp .env.example .env
```

Required Vite variables:

```bash
VITE_FIREBASE_API_KEY=
VITE_FIREBASE_AUTH_DOMAIN=
VITE_FIREBASE_PROJECT_ID=
VITE_FIREBASE_STORAGE_BUCKET=
VITE_FIREBASE_MESSAGING_SENDER_ID=
VITE_FIREBASE_APP_ID=
```

Never commit `.env`. It contains environment-specific Firebase configuration.

## Firebase Notes

Firebase Auth is used for login/register. Firestore stores user programs, completed sessions, active workout drafts, and app settings under the signed-in user.

If Firebase is not configured or a cloud request fails, the app keeps local-only mode and local fallback storage available through `localStorage`.

## Vercel Notes

Add the same `VITE_FIREBASE_*` variables from `.env.example` in the Vercel project settings under Environment Variables. Redeploy after changing any Firebase environment variable.

The Vite build output is generated by `npm run build`.
